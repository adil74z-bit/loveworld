LOVE WORLD - SETUP (sirf ek baar, ~15 minute, sab FREE)
=========================================================
Zaroori: phone ke browser (Chrome) mein "Desktop site" ON kar lo - GitHub aur Firebase ke pages aasan ho jaate hain.

PART 1 - Firebase (cloud save + online saath khelna)
1. console.firebase.google.com kholo -> Google account se login.
2. "Create a project" -> naam: loveworld -> Analytics OFF -> Create.
3. Left menu: Build -> Authentication -> Get started -> "Anonymous" -> Enable -> Save.
4. Left menu: Build -> Realtime Database -> Create Database -> location koi bhi -> "Start in locked mode" -> Enable.
5. Realtime Database ke upar "Rules" tab -> sab purana mita ke database.rules.json file ka poora text paste karo -> Publish.
6. Project Overview (ghar ka icon) -> "</>" (Web) icon -> app nickname: love -> Register app.
   Wahan firebaseConfig dikhega (apiKey, authDomain, databaseURL, projectId, appId). Isko copy karke rakho.
   NOTE: databaseURL na dikhe to Realtime Database page ke upar jo https://...firebaseio.com link hai wahi use karo.

PART 2 - GitHub (game ki website)
1. github.com -> free account banao.
2. "+" -> New repository -> naam: loveworld -> Public -> Create.
3. "uploading an existing file" -> ZIP ko pehle phone mein Extract kar lo (Files app -> zip -> Extract), phir saari files choose karke upload karo (index.html, sw.js, manifest.json, icon-192.png, icon-512.png, firebase-config.js, database.rules.json) -> Commit changes.
4. Repo ke Settings -> Pages -> Source: "Deploy from a branch" -> Branch: main, folder: / (root) -> Save.
5. 1-2 minute baad wahi page tumhara link dega: https://TUMHARA-NAAM.github.io/loveworld/

PART 3 - Config jodna
1. GitHub repo mein firebase-config.js kholo -> pencil (edit) icon.
2. PASTE_... wali values Firebase ki asli values se badlo (quotes " " rehne do) -> Commit changes.
3. 1-2 minute ruko.

PART 4 - Khelna
- Dono apne phone mein link kholo. Name likho + secret code 2025 -> dono ek hi island pe milenge.
- Chrome menu -> "Add to Home screen" = app jaisa icon.
- Android APK chahiye ho: pwabuilder.com -> apna link daalo -> Package for Android -> Download.
- Ek offline ho to uska avatar island pe soya hua dikhta hai; house/decor sab save rehta hai.

SECURITY: code 2025 chhota hai. Zyada private chahiye to mujhe bolo, lamba code laga dunga.
